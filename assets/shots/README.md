# 内置手动组合

20 组摄影组合在 [src/shot-presets.ts](../../src/shot-presets.ts) 中手工编排，引用 `assets/poses/library.json` 的既有姿势。不是照片识别数据，不使用已被否定的 AI 结果，也不调用云端模型。

| 分类 | 组合 |
| --- | --- |
| 肖像 | 正面柔光肖像、四十五度侧颜、侧身回眸、袖口与手势、交谈瞬间 |
| 时尚封面 | 经典封面站姿、低机位气场、秀场定格、收腰线条、松弛重心 |
| 写真集 | 背面廓形、侧面剪影线、向前一步、转身停格、展开廓形 |
| 其他：动作练习 | 山式平衡、单腿树式、战士横幅、舞台律动、芭蕾延伸 |

每组指定姿势、相机位置与目标、焦距、画幅和三灯参数；无背景图片及场景道具。姿势来源信息保留在姿势库中，其中交谈瞬间引用 Quaternius Standard 的交谈动画静态采样（CC0），其余引用项目已有姿势。

`thumbnails.json` 保存 20 张女性白模实际渲染的 JPEG 数据 URL，长边 320 像素。组合参数或姿势变更后需重新渲染，不能以占位图替换。总览见 [组合预览](../screenshots/shot-presets-contact-sheet.png)。

内置项随项目提供，与 SQLite 中的个人预设分开，不占个人保存额度且不能在列表删除。应用时保留当前所选人偶；换体型后可能需要微调关节或构图。AI 上传、分析、预览、另存功能保留，生成质量仍待改进。
